# Dados da APS

O programa gera registros **fictícios** de imagens de satélite para os experimentos de ordenação. Cada registro tem `id`, `data` (AAAAMMDD) e `nuvens` (0 a 100). Os cenários aleatório, ordenado e invertido são preparados pelo próprio programa.

O arquivo `exemplo.csv` contém dez registros fictícios no mesmo formato e serve apenas para testar a leitura de CSV. Nenhum resultado do projeto deve ser apresentado como medição de imagens ou catálogos reais do INPE/TerraBrasilis.
